# Умный анализатор финансов

Веб-приложение для учёта личных финансов: транзакции с автоматической категоризацией, бюджеты, финансовые цели, аналитика с графиками и уведомления. Проект по дисциплине «Технологии создания и поддержки ПО».

## Стек

Python, FastAPI, шаблоны Jinja2, графики Chart.js, PostgreSQL.
